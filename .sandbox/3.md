```bash
uv pip install -r requirements.txt

python -m logler serve --port 8000
# open http://localhost:8000  (UI is at /app)
```

### 2) Next-step build (adds the useful goodies)

**[Download — logler-nextstep.zip](sandbox:/mnt/data/logler-nextstep.zip)**

What’s improved:

* **Multi‑log tailing**: `WS /ws/multilog?paths=path1,path2,...` merges multiple files (arrival order). UI toggle for single vs multi.
* **Faster ingest**: a background **batch writer** pushes events into DuckDB (less per-line overhead).
* **Smarter regex path**: Rust **`RegexWrapper`** compiles once and exposes `is_match()` + batch `filter_flags()` (server uses it when present).
* **Richer search**: `/search` now supports `limit`, `offset`, `since`, `until`, `path`—handy for time-bounded queries.
* **UI quality**:

  * **Color rules** (localStorage): e.g., `ERROR=red;WARN=amber` for quick highlighting.
  * **Jump to next/prev mark** buttons (marks = `ERROR|WARN`) for fast triage.
  * Simple **search panel** to query DuckDB history (substring or regex).

Try it:

```bash
# Build Rust helper (optional), install deps, build UI — same as starter
python -m logler serve --port 8000
# In the UI:
# - Enter multiple paths (comma-separated), check "multi", Connect
# - Tweak color rules (e.g., ERROR=red;WARN=amber)
# - Use the search box to dig in history
```
